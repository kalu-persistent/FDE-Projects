# FDE Projects

A portfolio of practical **Forward Deployed Engineer (FDE)** projects focused on building AI-powered solutions for real customer and enterprise needs. The projects cover retrieval-augmented generation (RAG), integrations, agent workflows, document processing, evaluation, and operational visibility.

## Project catalog

| # | Project | Focus |
|---|---------|-------|
| 1 | [Enterprise knowledge assistant with permission-aware RAG](https://cloudsoftsol.com/blog/ai-fde-engineer-projects/#project-1-permission-aware-rag) | Answer questions from enterprise knowledge sources while respecting access permissions. |
| 2 | [Customer integration service](https://cloudsoftsol.com/blog/ai-fde-engineer-projects/#project-2-customer-integration-service) | Build a reliable API integration with retries and idempotency. |
| 3 | [ServiceNow or Jira ticket agent via MCP with human approval](https://cloudsoftsol.com/blog/ai-fde-engineer-projects/#project-3-ticket-agent-mcp) | Connect an agent to a ticketing system through MCP and require human approval for actions. |
| 4 | [IT-ops multi-agent incident summariser](https://cloudsoftsol.com/blog/ai-fde-engineer-projects/#project-4-it-ops-multi-agent) | Coordinate agents to summarize information about IT incidents. |
| 5 | [Secure banking or finance assistant](https://cloudsoftsol.com/blog/ai-fde-engineer-projects/#project-5-secure-banking-assistant) | Handle sensitive financial information with PII redaction and auditability. |
| 6 | [Document intelligence pipeline](https://cloudsoftsol.com/blog/ai-fde-engineer-projects/#project-6-document-intelligence) | Extract, validate, and route information from documents. |
| 7 | [Eval harness and CI regression gate for an LLM app](https://cloudsoftsol.com/blog/ai-fde-engineer-projects/#project-7-eval-harness-ci) | Evaluate an LLM application and catch regressions in CI. |
| 8 | [Observability and cost dashboard for an AI service](https://cloudsoftsol.com/blog/ai-fde-engineer-projects/#project-8-observability-cost-dashboard) | Make AI service behavior and usage costs visible. |
| 9 | [GitHub PR-review agent with guardrails](https://cloudsoftsol.com/blog/ai-fde-engineer-projects/#project-9-pr-review-agent) | Review pull requests with an agent while applying appropriate guardrails. |
| 10 | [Executive demo and ROI one-pager](https://cloudsoftsol.com/blog/ai-fde-engineer-projects/#project-10-executive-demo-roi) | Communicate a customer-engineering solution and its expected business value. |

## Working with this repository

Each project is an independent portfolio exercise. A project can be added in its own directory with its implementation, tests, and project-specific documentation. Document the problem being solved, how to run the solution, and any assumptions or limitations alongside the code.

The project ideas are based on [AI FDE engineer project ideas](https://cloudsoftsol.com/blog/ai-fde-engineer-projects/).
